# Contributing

Issues and pull requests are welcome.

- **Bug or idea:** open an issue describing what happened or what you would change, and why. For a larger change, open the issue before the PR.
- **Pull request:** fork the repository, create a branch from `main` and open the PR against `main`.
  - Test it: run `./apply.sh` on a new directory and say in the PR what you ran.
  - Write in English and keep the docs short.
  - Use [Conventional Commits](https://www.conventionalcommits.org/) for commits and the PR title, like `fix: keep existing hooks in extensions.yml`.
  - One change per PR.
